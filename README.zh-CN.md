# Yauzin（邮笺）

[English](README.md) | **简体中文**

用 Go + [Gio](https://gioui.org) 编写的桌面邮件客户端，界面参考 Gmail 网页版。它通过 Gmail API 读取真实邮箱，同时始终内置一个演示账号，未填写任何凭据时也能直接打开查看。

## 功能

- 账号：在「设置 → 账号 → 添加账号」里使用自己的 Google Cloud OAuth 客户端（桌面应用并启用 Gmail API，PKCE 授权、一次性 127.0.0.1 回环回调）添加多个 Gmail 账号，可重新登录、删除账号，在顶栏账号菜单切换当前账号并让下次启动优先打开它；每个账号可单独选择走代理或直连。演示邮箱始终存在。
- 两栏布局：256dp 侧栏（收件箱、已加星标、已发送、垃圾邮件、垃圾箱，以及按 Gmail 层级、颜色展示并可折叠的标签）+ 单一内容卡片，在会话列表与正文之间切换；顶栏有折叠、搜索、设置与账号菜单。
- 搜索：顶栏一次搜索全部文件夹（不含垃圾邮件与垃圾箱），查询原样交给后端，因此 `from:`、`subject:`、`has:attachment` 等 Gmail 语法可用；结果列表保留翻页工具栏。
- 会话列表：同一会话合并为一行（参与者、主题、摘要、时间、星标、未读加粗、标签色块），每页 25 个、游标翻页；行内悬停归档/删除/标记已读或未读，工具栏有三态全选框，支持批量归档/删除/标记已读或未读，菜单里还有「全部标记为已读」。
- 阅读：整段会话按时间排列、逐封折叠；正文为纯文本，每封邮件的「更多」菜单可在系统浏览器打开安全预览（严格 CSP）、完整预览或原始 RFC 822 邮件；星标/已读/归档/删除作用于整个会话。
- 写信：新邮件、回复与转发，支持抄送、密送、附件与发送状态反馈，可最小化到标题栏，发送只能用「发送」按钮（没有快捷键）。发件人可以是一个已配置的 SMTP 发信账号（「设置 → 账号 → 发信账号」或添加账号时选 SMTP），并可默认密送一份到当前 Gmail 账号。引用排版与 Gmail 一致且固定英文（回复是 `On <时间> <发件人> wrote:` 加逐行 `> `，转发是 `---------- Forwarded message ----------`）；正文有选区时回复只引用选中片段，回复写在引用下方，转发写在引用上方。
- 托盘与通知：关闭窗口后进程留在通知区并显示未读红点；每分钟检查一次邮箱，有新未读会话时发送 Linux 桌面通知（最多 3 条主题 + 未读会话数）。再次启动会通过 D-Bus 唤醒正在运行的窗口，而不是再开一个进程。
- 设置：界面语言（中文/英文，默认跟随系统）、客户端标题栏（Wayland）、性能监视器、代理、日志级别，以及账号管理（添加、重新登录、删除、按账号代理）。
- 键盘：/、C、Esc、E、Delete、S、U、J/K、Enter、X、R、F，Ctrl+W 关闭窗口、Ctrl+Q 退出程序；完整键表见「设置 → 快捷键」。

## 配置文件

`os.UserConfigDir()/yauzin/` 下有两个文件：`settings.json`（偏好设置）与 `accounts.json`（OAuth 客户端凭据、令牌与按账号选项）。两者均以 0600 权限、临时文件 + rename 原子写入；`YAUZIN_CONFIG_DIR` 可同时替换两者的目录。

## 已知限制

- Gmail 账号申请 `gmail.modify` 权限：加星标、归档、标记已读/未读、删除（移入垃圾箱，不会永久删除）与发送都会写回邮箱。把权限范围扩大之前授权的账号读邮件照常，但要重新登录一次才能执行这些动作；保存附件仍提示「当前账号不支持该操作」。
- 通过 SMTP 发信账号发出的邮件不会出现在 Gmail 的「已发送」里；需要留档时勾选该账号的「默认密送到当前 Gmail 账号」，或每封自己填写密送地址。SMTP 密码与 OAuth 凭据一样明文存放在 0600 的 `accounts.json` 中。
- 演示邮箱及从中发出的邮件不落盘，重启恢复演示数据；草稿同样不保存。
- 收件箱轮询只维护托盘徽标与通知：已打开的窗口需要手动刷新（工具栏刷新）、重开窗口或点击通知才会更新。
- 桌面通知仅限 Linux（D-Bus）。没有通知区时托盘不可用，关闭窗口即退出程序。
- 正文只渲染 `text/plain`；HTML 交给系统浏览器，内嵌图片不显示，纯文本里的链接不可点击。
- 侧栏不显示除收件箱/已加星标/已发送/垃圾邮件/垃圾箱以外的系统标签（草稿、重要、分类）；垃圾邮件只做浏览与既有动作（已读、星标、删除到垃圾箱），没有「标记为垃圾邮件 / 不是垃圾邮件」与清空垃圾邮件；也没有统一收件箱、标签管理、IMAP 支持（只有出站 SMTP 发信账号）或离线缓存。
- 客户端标题栏仅在 Wayland 可用（X11 始终使用服务端装饰）；KDE 上需先添加「无标题栏和边框」窗口规则，且启用期间无法拖动窗口边缘缩放。
