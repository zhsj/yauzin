# Yauzin（邮笺）

[English](README.md) | **简体中文**

用 Go + [Gio](https://gioui.org) 编写的桌面邮件客户端，界面参考 Gmail 网页版。**当前阶段：界面 + mock 后端**——数据全部来自内存演示账号，不联网、不需要凭据。

## 功能

- 两栏布局：侧栏（收件箱、已加星标、已发送、垃圾箱与标签）+ 内容区，在会话列表与正文之间切换；顶栏有折叠、搜索、设置与账号菜单。
- 会话列表：同一会话合并为一行（参与者、主题、摘要、时间、星标、未读加粗），每页 50 个；悬停归档/删除/已读，工具栏支持三态全选与批量操作。
- 阅读：整段会话按时间排列、逐封折叠；正文为纯文本，HTML 交给浏览器；星标/已读/归档/删除作用于整个会话。
- 写信：新邮件、回复与转发，支持抄送、附件与发送状态反馈，可最小化到标题栏。
- 键盘：J/K、Enter、X、E、Delete、S、U、R、F、C、/、Ctrl+Enter，Ctrl+W 关闭窗口、Ctrl+Q 退出程序；完整键表见「设置 → 快捷键」。
- 界面语言：中文/英文，跟随系统并可切换，立即生效并写入配置文件。

## 设置文件

`os.UserConfigDir()/yauzin/settings.json`（0600，原子写入）；`YAUZIN_CONFIG_DIR` 可换目录。

## 已知限制

- 账号与邮件不落盘，重启恢复演示数据；草稿、统一收件箱、通知与后台同步未实现。
- 正文只渲染 `text/plain`，链接不可点击、内嵌图片为占位，附件为 mock 占位文件。
